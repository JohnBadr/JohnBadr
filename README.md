## Featured projects

- **[MeshUSF](https://github.com/MeshUSF/MeshUSF-client)** — Off-grid communication for USF’s Community Emergency Response Team using Flutter, MeshCore, and LoRa radios. I lead a 6-person team and built Bluetooth auto-reconnect with message queuing, plus contact and location sharing. Now building an offline map and incident planning system that shares plans over LoRa using packet fragmentation.
- **[LeaveOnTime](https://github.com/JohnBadr/leave-on-time)** — Building a real-time USF bus tracker to figure out when to leave to catch the bus. Its Python and SQLite pipeline on Azure recorded over 8 million arrival forecasts for evaluating ETA accuracy. Next step: using the data to train an ML model.
- **[ESP32 Embedded Systems](https://github.com/JohnBadr/Embedded-Systems-Learning-Log)** — Nine documented C++ projects covering sensors, motors, and displays.
